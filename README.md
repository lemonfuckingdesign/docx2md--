# docx2md

批量把中文党政机关的法规、制度、通知、政策解读类 `.docx`，转换成适合 **Dify 知识库入库**的 Markdown（带 YAML front matter），并生成一份质检清单 `处理清单.csv`。

核心理念：**文字零改写，只调整结构与元数据**——原文一个字都不改，只重建标题层级、补元数据、做覆盖率校验。

## 功能特性

- 一个 `.docx` → 一个同名 `.md`；一篇文档内含多篇时合并输出，不拆成多个文件
- 自动识别四种体例，按原文编号重建 `##` / `###` / `####` 层级
- YAML front matter 写入 `title` / `doc_number` / `issuer` / 各类日期 / `structure_type` 等字段，便于 Dify 元数据筛选
- 落款日期通吃阿拉伯数字（`2025年3月1日`）与中文数字（`二〇二五年三月一日`）
- 标题降级去重、断句合并、粘连段落拆分、截断问句还原
- 内容覆盖率校验，异常项写入清单，方便抽查
- 提供「扁平模式」（`--flat`），把 `###` 及以下标题还原为正文，避免知识库切出「只有标题」的碎块

## 支持的四种体例（自动识别，优先级从上到下）

1. **问答体例** —— `问：…／答：…` 的答记者问、访谈、政策问答，输出 `## 第N问 {主题}` + `**问：**` + `**答：**`
2. **章条体例** —— `第X章／第X条` 的法规，输出 `## 第X章` / `### 第X条`，附章节索引
3. **公文编号体例** —— `一、／（一）／1.／①` 多级编号，压缩成连续层级，文头与落款单独成块
4. **无编号文本** —— 按段落与语义长度兜底切分

> 一个 docx 含多篇时：以「篇N」行为界切分，逐篇判断体例后合并，外层用 `## 第N篇` 分节，篇内标题整体降一级，YAML 写入 `part_count`。

## 快速开始

环境要求：**Python 3.8+**（代码使用了海象运算符 `:=`）。

```bash
# 1. 安装依赖（唯一第三方依赖 python-docx）
pip install -r requirements.txt

# 2. 命令行转换
python docx2md.py <输入文件夹>                      # 结果写到 <输入>/dify_md/
python docx2md.py <输入文件夹> <输出文件夹>          # 指定输出目录

# 一键脚本（会自动检测 Python 并安装依赖）
# Windows：双击 一键转换.bat
# macOS / Linux：chmod +x 一键转换.sh && ./一键转换.sh
```

## 命令行用法

```
python docx2md.py [-h] [-o 输出目录] [--flat] [-v] [--log-file 文件] [--version] 输入目录 [输出目录] [flat]
```

| 参数 | 说明 |
| --- | --- |
| `输入目录`（必填） | 递归扫描其下所有 `.docx`（忽略 `~$` 开头的临时文件） |
| `输出目录`（可选） | 默认 `<输入目录>/dify_md` |
| `flat`（可选位置参数） | 兼容旧用法，等同 `--flat`；传其他值会被忽略 |
| `-o`, `--output` | 指定输出目录，与位置参数同时给出时以本项为准 |
| `--flat` | Dify 扁平模式：`###` 及以下标题还原为正文 |
| `-v`, `--verbose` | 输出 DEBUG 级日志 |
| `--log-file 文件` | 除控制台外，额外把日志写入指定文件（UTF-8） |
| `--version` | 显示版本号 |
| `-h`, `--help` | 显示帮助 |

示例：

```bash
python docx2md.py ./法规 -o ./out --flat -v --log-file run.log
```

## 输出说明

默认输出到 `<输入文件夹>/dify_md/`：

```
dify_md/
├── 办法一.md
├── 办法二.md
└── 处理清单.csv
```

`处理清单.csv`（UTF-8 with BOM，可直接用 Excel 打开）列：

| 列 | 含义 |
| --- | --- |
| 源文件 | 原始 docx 文件名 |
| 体例 | 识别出的体例（或 `合集（N篇）`） |
| 状态 | `正常` / `条文缺失` / `内容不全` / `失败` |
| 章数 / 节数(问答数) | 结构统计 |
| 内容覆盖率 | 原文落入 md 的字符比例，越接近 100% 越放心 |
| 备注 / 输出文件 | 异常说明与产物路径 |

## Dify 入库建议

| 选项 | 建议值 |
| --- | --- |
| 分段模式 | 自定义 |
| 分段标识符 | `\n### `（按小节切，推荐）；章条式与公文式混批时用 `\n## ` 统一 |
| 分段最大长度 | 500 ~ 800 |
| 分段重叠长度 | 0 ~ 50 |
| 索引方式 | 高质量（向量） |
| 检索方式 | 混合检索，开启关键词索引 |
| 元数据映射 | `title`、`date_issued`、`structure_type` |

## 已知限制

- 表格内容会被读取并附在正文之后，表格与正文在原文中的先后顺序可能改变（正文文字本身不丢）
- 转换规则针对中文党政公文做了较多启发式调校，阈值集中在 `config.py`，其他语种/版式需自行评估
- 加密或损坏的 docx 无法解析，请先用 Word 打开另存一次

## 开发与验证

项目未内置测试目录。重构时采用「自造样例 + SHA-256 对比」保证输出不变：用 `python-docx` 生成覆盖四类体例的最小样例，对比转换前后 md/csv 的哈希。
